ゲームの作りたい内容が決まっても、いきなりBlueprintを組み始めると、何を作ればよいか分からなくなることがあります。
今回は**ゲームを必要な機能に分ける → UEでの実現方法を調べる → 作って動かす**、という進め方を練習します。次回からのオリジナルゲーム制作でも同じ方法を使います。

<Prerequisites>

- Unreal Engine **5.7.4** を使用する
- キャラクターの操作、Actor、Collision、変数、Widget、Blueprintの基本を学習済み
- このページの制作では、新規プロジェクトを **Games → First Person → Variant: Arena Shooter（Blueprint）** で作る
- 作業メモを保存できる場所を用意する（2列の表を記入できれば形式は自由）

</Prerequisites>

| 時間の目安 | 内容 |
| --- | --- |
| 2限・前半 | 例題①と②で、必要な機能を洗い出す |
| 2限・後半 | 例題①と②で、UEでの実現方法を考える・調べる |
| 3限 | 例題②を実際に制作する |
| 4限（自習） | 制作・動作確認を続け、完成したら追加仕様に挑戦する |

### 例題①｜スーパーマリオ64の赤コイン

[参考動画：『スーパーマリオ64』ボムへいのせんじょう「8まいの あかコイン」](https://www.youtube.com/watch?v=zsa13zxeseY)

この例題では、マリオ64のゲーム全体は分析しません。対象は**次の仕様に関係する部分だけ**です。

> ステージ内に8枚の赤コインがあります。プレイヤーが赤コインに触れると取得できます。8枚すべてを集めるとパワースターが出現し、そのスターを取得するとミッションクリアになります。

<Action title="教員と一緒に、必要な機能を挙げる">

動画と仕様を確認し、ゲームができるようになるために必要な機能を考えます。「8枚集めた」と判断するには何が必要か、スターはいつ出すか、という順に考えてみましょう。

| 赤コインを取得できる | |

</Action>

### 演習1｜VALORANTの射撃テストに必要な機能

<Exercise>

次は、実際に制作するゲームを分析します。

[参考動画：『VALORANT』射撃場のプレイ映像（2026年9月15日）](https://www.youtube.com/watch?v=2MGkR6GOZHY)

映像にはノーマル／ハードの練習場面も含まれます。まず**STARTパネル・ボットの出現・SCOREとREMAININGの表示板**に注目してください。基本制作ではスピードモードのEasyを固定で使います。

**制作する基本仕様**

> FPS視点で射撃場のボットを撃ち、30回の出現機会で何体倒せるかを競います。
>
> - 射撃場内の操作パネルの**STARTを銃で撃つ**とテストが始まります。
> - ボットは射撃場のランダムな位置に**1体ずつ**出現します。
> - ボットを倒すと1点獲得します。一定時間内に倒せなければボットは消え、得点にはなりません。その後、次のボットが出現します。
> - ボットの出現機会は**合計30回**です。30回分が終わるとテストが終了します。
> - **SCORE**（獲得点数）と**REMAINING**（残りの出現回数）は、画面上のHUDではなく、**射撃場の3D空間内に設置したデジタル表示板**に表示します。
> - 終了後は最終スコアを確認でき、再びSTARTを撃つと新しいテストを始められます。

今回は**このスキルテストだけ**を制作します。VALORANT全体のメニュー、オンライン対戦、武器ショップ、エージェントの能力などは対象ではありません。射撃場の背景やボットの見た目は、機能を確認できる範囲で制作してください。

### 例題①｜赤コインの実現方法（教員の実演）

<Action title="例題①の表に、UEでの実現方法を記入する">

左列の機能ごとに、どんな仕組みが使えそうかを考えます。以下は一例であり、唯一の作り方ではありません。

| 必要な機能 | UEでの実現方法（例） |
| --- | --- |
| 赤コインを取得できる | コインActorでOverlapを検知し、取得後にDestroy Actor |

| スターを取得したらクリアになる | 取得時にクリア処理を実行する |

「コインを取得する UE5 Blueprint」など、**機能をそのまま検索語にする**方法も使えます。検索結果を見つけたら、現在のUEバージョンや既存のBlueprintで使えるかを確認します。

### 演習2｜射撃テストの実現方法

<Exercise>

演習1で作った表の右列を埋めてください。既習の仕組み、[Epic公式のFirst Personテンプレート説明](https://dev.epicgames.com/documentation/unreal-engine/first-person-template-in-unreal-engine?lang=ja)、検索、AIなどを使って構いません。

「使えそうな仕組み」まで分かれば記入できます。まだ分からないものは**「未調査」や「要確認」**と書いて構いません。制作中に見直せます。

**完成の目安：** それぞれの機能について、実装を試すための手掛かりがある、または未解決の調査対象を具体的に書けていることです。

<Hint>

まず、Arena Shooterテンプレートで操作・銃の発射・命中処理を試してください。3D空間の文字表示は「Widget Component」、一定時間後の処理は「Timer」や「Delay」、ランダムな位置への出現は「Spawn Actor」を手掛かりに調べられます。

</Hint>

<Answer>

**右列の候補例**です。制作前にすべてのBlueprintを設計する必要はありません。作りながら使える機能を流用します。

| 必要な機能 | UEでの実現方法の候補 |
| --- | --- |
| FPS視点の操作・射撃 | Arena Shooterのキャラクター・銃の処理を確認して利用 |
| STARTを撃って開始 | パネルActorへの命中を検知して開始処理を呼ぶ |
| ボットを1体ずつランダム出現 | 複数の出現位置から選択し、Spawn Actorで生成 |
| ボットの命中・撃破 | Arena Shooterの射撃処理・ダメージ／命中判定を調査して利用 |
| 一定時間でボットが消える | Timer等で制限時間後に消去。撃破済みなら二重処理しない |
| スコアと残り回数を管理 | Integer変数を更新し、撃破／時間切れの両方で次へ進む |
| 30回終了を判定 | 処理済み回数を判定し、次の生成を止める |
| 3D表示板のデジタル表示 | Widget BlueprintをWidget Componentでワールド空間に置き、数値を更新 |
| 最終結果・再挑戦 | 最終点数を維持し、再START時に初期化して再開始 |

ターゲットとして既存のAI敵をそのまま使う必要はありません。今回の仕様は**撃って得点になるボット**なので、AI移動や反撃などが不要なら、シンプルなActorにしても構いません。

</Answer>

</Exercise>

</Section>

<Section title="Arena Shooterで実際に制作しよう" goal="調べた機能を実装し、スキルテストを最初から最後まで遊べる状態にする">

<Action title="新規プロジェクトを作り、テンプレートの動作を確かめる">

Unreal Engine **5.7.4** のプロジェクト作成画面で、`Games` → `First Person` → `Variant: Arena Shooter` を選び、Blueprintプロジェクトを作ります。

まずPlayし、**移動・視点操作・射撃・命中時の挙動**を確認します。すでに利用できる機能は作り直さず流用します。既存サンプルを残しておきたい場合は、作業用のレベルを別名で保存してください。

</Action>

<Action title="機能ごとに作り、Playして確認する">

演習で作った2列の表を見ながら、作れそうな機能から取り掛かります。実装方法は1つではありません。調べた方法が使えなければ、別の方法を試し、表も修正します。

- まず単独の機能を作って試す（例：STARTへの命中、ボット1体の生成、3D表示板）
- 動いた機能をつなぎ、1回のテスト開始から終了まで通して試す
- 不具合を見つけたら、発生条件を確かめて直す

</Action>

<Checkpoint title="基本仕様の完成チェック">

- STARTを**撃つ前**にはスキルテストが始まらない
- STARTを撃つとテストが始まり、SCOREは`0`、残り回数は`30`から新しい挑戦になる
- ボットの出現位置が変化し、同時に出るボットは**最大1体**
- ボットを倒すとスコアが**ちょうど1**増え、次の出現機会へ進む
- 撃たずに待つとボットが時間切れで消え、**加点せず**次へ進む
- 1体に繰り返し命中させても、同じ出現機会では二重に加点されない
- 撃破・時間切れのいずれでも出現機会は1回分だけ消費され、**合計30回**で終了する
- 30回終了後は新しいボットが出現せず、最終スコアは`0`〜`30`の範囲にある
- SCOREとREMAININGは**3D空間内の表示板**にあり、プレイ中に正しく更新される
- 終了後にSTARTを撃つとスコアと残り回数が初期化され、もう一度遊べる

</Checkpoint>

<Recovery title="うまく動かないときの確認ポイント">

- STARTを撃っても反応しない：弾が何に当たっているか、パネル側の命中・Collision設定、開始処理の呼び出し先を確認する
- ボットが複数出る：撃破と時間切れの両方から、同じ出現機会の終了処理が実行されていないか確認する
- SCOREが2増える：命中イベントが複数回起きても、一度倒したボットから再加点されないか確認する
- 30回を超える：残り回数を減らす時点と、次のボットを出す条件を確認する
- 表示板が見えない：Widget Componentの向き、サイズ、表示設定と、表示数値の更新先を確認する
- リトライで値が残る：再開時にSCORE、残り回数、ボットの状態を初期化しているか確認する

</Recovery>

</Section>

<Section title="完成したら、実際の射撃場の追加仕様へ" goal="基本仕様を保ったまま、実在する射撃場の別機能を選んで拡張する">

基本仕様の完成チェックがすべてできたら、次の追加仕様に挑戦しましょう。**必須ではありません。** 1つずつ追加し、その都度動作確認します。

### 演習-発展1

<Exercise>

射撃場の設定として、**Easy・Medium・Hard**を切り替えられるようにしてください。難易度によってボットが出現している時間が変わり、選んだ設定で30回のテストが最後まで実行できれば完成です。

<Hint>

ボットの寿命を決める値を1か所で管理し、難易度の選択結果によって値を切り替える方法を考えましょう。設定画面の有無も含め、実際のVALORANTの操作を参考にしてください。

</Hint>

<Answer>

難易度ごとの表示時間を管理する変数を用意し、テスト開始時に選択中の値を使ってボットの消滅処理を予約する方法があります。元の30回終了・再挑戦・二重加点防止が壊れていないことも確認します。

</Answer>

</Exercise>

### 演習-発展2

<Exercise>

実際の射撃場にある**ボットのアーマー設定**または**弾薬無限設定**を追加してください。設定のON／OFFによって動作が変化し、どちらの状態でもスキルテストが終了できれば完成です。

<Hint>

アーマーならダメージの扱い、弾薬無限なら銃の弾数消費処理を確認します。Arena Shooterで使っている処理を先に調べましょう。

</Hint>

<Answer>

アーマーの有無に応じてボットの耐久値や受けるダメージを変える、または弾薬無限がONのときだけ弾数消費を抑える方法があります。設定を変更しても、スコアは撃破したボット1体につき1点のままです。

</Answer>

</Exercise>

### 演習-発展3

<Exercise>

VALORANT射撃場の別モードである**50体／100体撃破**に挑戦してください。ボットを指定数だけ倒すまでの所要時間を計測し、最後の1体を倒すと計測が止まれば完成です。これは30回の出現機会を使う基本のスピードモードとは別ルールです。

<Hint>

失敗時に消える基本モードとは違い、撃破数を達成するまで続く仕組みにします。出現回数と撃破数を混同しないようにしましょう。

</Hint>

<Answer>

「スピードモード」と「50体／100体撃破モード」で終了条件を切り替える方法があります。撃破モードは指定数の撃破で終了し、経過時間を表示します。基本の30回・SCORE表示の動作も残します。

</Answer>

</Exercise>
