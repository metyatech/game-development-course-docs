ゲームの作りたい内容が決まっても、いきなりBlueprintを組み始めると、何を作ればよいか分からなくなることがあります。
今回は**ゲームを必要な機能に分ける → UEでの実現方法を調べる → 作って動かす**、という進め方を練習します。次回からのオリジナルゲーム制作でも同じ方法を使います。

<Prerequisites>

- Unreal Engine **5.7.4** を使用する
- キャラクターの操作、Actor、Collision、変数、Widget、Blueprintの基本を学習済み
- このページの制作では、新規プロジェクトを **Games → First Person → Variant: Arena Shooter（Blueprint）** で作る
- 作業メモを保存できる場所を用意する（3列の表を記入できれば形式は自由）

</Prerequisites>


<Section title="まず、ゲームを機能に分けてみよう" goal="ゲームの仕様から必要な機能を見つけ、実装方法とは分けて考えられるようになる">

<Concept title="「必要な機能」「実装場所」「実装方法」を分けて考えよう">

| --- | --- | --- |
| （何ができるか） | （どこに作るか） | （どう実現するか） |
</Concept>

### 演習1｜VALORANTの射撃テストに必要な機能

<Exercise>

次は、実際に制作するゲームを分析します。

[参考動画：『VALORANT』射撃場のプレイ映像（2026年9月15日）](https://www.youtube.com/watch?v=2MGkR6GOZHY)

動画の**「開始」パネル・ボットの出現・「スコア」と「残り」の表示板**に注目してください。基本制作ではスピードを「ノーマル」に固定します。

**制作する基本仕様**

> FPS視点で射撃場のボットを撃ち、30回の出現機会で何体倒せるかを競います。
>
> - 射撃場内の**「開始」パネルを銃で撃つ**とテストが始まります。
> - ボットは射撃場のランダムな位置に**1体ずつ**出現します。
> - ボットを倒すと1点獲得します。一定時間内に倒せなければボットは消え、得点にはなりません。その後、次のボットが出現します。
> - ボットの出現機会は**合計30回**です。30回分が終わるとテストが終了します。
> - **「スコア」**（獲得点数）と**「残り」**（残りの出現回数）は、画面上のHUDではなく、**射撃場の3D空間内に設置した表示板**に表示します。
> - 終了後は最終スコアを確認でき、再び「開始」を撃つと新しいテストを始められます。

今回は**この射撃テストだけ**を制作します。VALORANT全体のメニュー、オンライン対戦、武器ショップ、エージェントの能力などは対象ではありません。射撃場の背景やボットの見た目は、機能を確認できる範囲で制作してください。

### 例題①｜赤コインの実現方法（教員の実演）

<Action title="例題①の表に実装場所と実装方法を記入する">

先ほど作った表の右2列を、教員と一緒に考えましょう。**どのBlueprintが担当するか**と、**そこで何を行うか**を分けて書きます。

<details>
<summary>回答例を見る</summary>

| 必要な機能 | 実装場所 | 実装方法 |
| --- | --- | --- |
| 赤コインを取得する | `BP_RedCoin` | プレイヤーとのOverlapを検知し、`BP_RedCoinMission`に取得を通知して自身を消す |
| 取得枚数を管理する | `BP_RedCoinMission` | `RedCoinCount`（Integer）を用意し、コインからの通知を受けると1加算する |
| 8枚取得したらスターを出現させる | `BP_RedCoinMission` | 取得枚数が8になったら、指定位置に`BP_PowerStar`をSpawnする |

この表は設計例です。例えば「コインを取得する UE5 Blueprint」のように機能を検索語にして、ほかの実装方法も調べられます。

### 演習2｜射撃テストの実現方法

<Exercise>

演習1で作った表の**「実装場所」と「実装方法」**を埋めてください。
まだ分からないものは**「？」**、自信がないものは**「Spawn Actor？」**のように「？」を付けておいても構いません。

<Hint>

まず、Arena Shooterテンプレートで操作・銃の発射・命中処理を試してください。3D空間の文字表示には「Widget Component」、一定時間後の処理には「Timer」、ランダムな位置への出現には「Random Float in Range」と「Spawn Actor」が手掛かりになります。

</Hint>

<Answer>

**回答例**です。実装場所も含めて一例なので、学生が同じBlueprint構成にする必要はありません。

| 必要な機能 | 実装場所 | 実装方法 |
| --- | --- | --- |
| FPS視点で銃を撃つ | Arena Shooterのキャラクター・銃 | テンプレートの移動・射撃・命中処理を確認し、利用する |
| 「開始」を撃ってテストを始める | `BP_StartPanel` | パネルへの命中を検知し、`BP_ShootingTestManager`の開始処理を呼ぶ |
| ボットをランダムな位置に1体ずつ出す | `BP_ShootingTestManager` | `Random Float in Range`でX・Y座標を決め、Z座標は固定して`Spawn Actor`する |
| ボットを撃破する | `BP_TargetBot` | 命中を検知し、`BP_ShootingTestManager`に撃破を通知する |
| 時間切れのボットを消す | `BP_ShootingTestManager` | Timerで制限時間後にボットを消し、次の出現へ進める |
| 撃破時にスコアを増やす | `BP_ShootingTestManager` | Integer変数`Score`を撃破時に1加算する |
| 残り回数を管理する | `BP_ShootingTestManager` | Integer変数`Remaining`を30で開始し、出現機会が終わるごとに1減らす |
| テストを終了する | `BP_ShootingTestManager` | 30回の出現機会が終了したら次の生成を止める |
| 3D表示板に「スコア」と「残り」を表示する | `BP_Scoreboard`と`WBP_Scoreboard` | `BP_Scoreboard`のWidget Componentに`WBP_Scoreboard`を設定し、Managerの数値をWidgetへ渡して表示する |
| 最終スコアを残し、再挑戦する | `BP_ShootingTestManager` | 終了後はScoreを維持し、再び「開始」が撃たれたらScoreを0、Remainingを30に戻す |

`BP_ShootingTestManager`はテストの進行と数値管理、`WBP_Scoreboard`は表示を担当します。`BP_Scoreboard`はWidget Componentを使って表示板を3D空間に置くActorです。
ボットとして既存のAI敵を必ず使う必要はありません。移動や反撃が不要なら、シンプルなActorで実装できます。

</Answer>

</Exercise>

</Section>

<Section title="Arena Shooterで実際に制作しよう" goal="調べた機能を実装し、スキルテストを最初から最後まで遊べる状態にする">

<Action title="新規プロジェクトを作り、テンプレートの動作を確かめる">

Unreal Engine **5.7.4** のプロジェクト作成画面で、`Games` → `First Person` → `Variant: Arena Shooter` を選び、Blueprintプロジェクトを作ります。

まずPlayし、**移動・視点操作・射撃・命中時の挙動**を確認します。すでに利用できる機能は作り直さず流用します。既存サンプルを残しておきたい場合は、作業用のレベルを別名で保存してください。

</Action>

<Action title="機能ごとに作り、Playして確認する">

演習で作った2列の表を見ながら、作れそうな機能から取り掛かります。実装方法は1つではありません。調べた方法が使えなければ、別の方法を試し、表も修正します。

- まず単独の機能を作って試す（例：「開始」への命中、ボット1体の生成、3D表示板）
- 動いた機能をつなぎ、1回のテスト開始から終了まで通して試す
- 不具合を見つけたら、発生条件を確かめて直す

</Action>

<Checkpoint title="基本仕様の完成チェック">

- 「開始」を**撃つ前**にはスキルテストが始まらない
- 「開始」を撃つとテストが始まり、スコアは`0`、残り回数は`30`から新しい挑戦になる
- ボットの出現位置が変化し、同時に出るボットは**最大1体**
- ボットを倒すとスコアが**ちょうど1**増え、次の出現機会へ進む
- 撃たずに待つとボットが時間切れで消え、**加点せず**次へ進む
- 1体に繰り返し命中させても、同じ出現機会では二重に加点されない
- 撃破・時間切れのいずれでも出現機会は1回分だけ消費され、**合計30回**で終了する
- 30回終了後は新しいボットが出現せず、最終スコアは`0`〜`30`の範囲にある
- 「スコア」と「残り」は**3D空間内の表示板**にあり、プレイ中に正しく更新される
- 終了後に「開始」を撃つとスコアと残り回数が初期化され、もう一度遊べる

</Checkpoint>

<Recovery title="うまく動かないときの確認ポイント">

- 「開始」を撃っても反応しない：弾が何に当たっているか、パネル側の命中・Collision設定、開始処理の呼び出し先を確認する
- ボットが複数出る：撃破と時間切れの両方から、同じ出現機会の終了処理が実行されていないか確認する
- スコアが2増える：命中イベントが複数回起きても、一度倒したボットから再加点されないか確認する
- 30回を超える：残り回数を減らす時点と、次のボットを出す条件を確認する
- 表示板が見えない：Widget Componentの向き、サイズ、表示設定と、表示数値の更新先を確認する
- リトライで値が残る：再開時にスコア、残り回数、ボットの状態を初期化しているか確認する

</Recovery>

</Section>

### 演習-発展1｜スピードを切り替える

<Exercise>

実際のVALORANTでは、**F3キー**で設定画面を開き、「スピード」を**イージー・ノーマル・ハード**から選べます。[参考動画の2:14から、設定画面を確認できます](https://www.youtube.com/watch?v=2MGkR6GOZHY&t=134s)。

| スピード | 違い |
| --- | --- |
| イージー | ボットが長く表示され、狙う時間がある |
| ノーマル | イージーより短い時間で消える |
| ハード | 最も短い時間で消える |

制作した射撃テストでも、3段階を切り替えられるようにしてください。選んだスピードでボットの表示時間が変わり、30回のテストが最後まで実行できれば完成です。設定を切り替える画面や操作方法は自由です。

<Hint>

ボットが消えるまでの時間を変数で管理し、選択したスピードによって値を変える方法を考えましょう。

</Hint>

<Answer>

`BP_ShootingTestManager`にスピード設定と表示時間を管理する変数を用意します。ボットを出現させる際に、選択された表示時間をTimerに渡す方法があります。具体的な秒数は自分で調整してください。

</Answer>

</Exercise>

### 演習-発展2｜弾薬無限をON／OFFにする

<Exercise>

VALORANT射撃場の設定には**「弾薬無限」**があります。ONなら弾が減らず、OFFなら撃つたびに装填弾数が減ります。OFFでは**Rキーでリロード**し、銃に弾を補充して再び撃ちます。

制作したゲームにも、弾薬無限のON／OFFを切り替える機能を追加してください。今回の制作では**初期状態をON**とし、OFFでは次のように動作させます。

- 弾を1発撃つごとに、装填弾数が1減る
- 装填弾数が0になったら撃てない
- Rキーを押すとリロードし、装填弾数が最大まで回復して再び撃てる

**今回は簡略版です。** 予備弾薬の管理や、弾を使い切ったあとの武器購入は実装しません。リロードのアニメーションも必須ではありません。ON／OFFの両方で射撃テストを最後まで遊べれば完成です。

<Hint>

まずArena Shooterの銃に、弾数やリロードの処理があるか確認してください。すでにある場合は流用します。ない場合は、装填弾数のInteger変数と、撃てるかどうかの判定を用意します。

</Hint>

<Answer>

銃を管理するBlueprintに`InfiniteAmmo`（Boolean）、`AmmoInMagazine`と`MagazineCapacity`（Integer）を用意する方法があります。OFFでは撃つと`AmmoInMagazine`を1減らし、0なら射撃を止めます。Rキーの入力で`AmmoInMagazine`を`MagazineCapacity`に戻します。ONでは装填弾数を消費しないようにします。

</Answer>

</Exercise>

### 演習-発展3｜50体／100体排除モード

<Exercise>

[参考動画：VALORANT射撃場の100体排除を含むプレイ映像](https://www.youtube.com/watch?v=zF2ynHpLmAY)

VALORANT射撃場の別モードである**50体／100体排除**に挑戦してください。参考動画を見て、30回の出現機会で得点を競うスピードモードとの違いを確認しましょう。

このモードではボットを指定数だけ倒すまでの**所要時間**を計測します。ボットは時間経過だけでは消えず、最後の1体を倒すと計測が止まれば完成です。基本の30回モードとは別のルールにします。

<Hint>

基本モードの「出現回数」と、このモードの「撃破数」を混同しないようにしましょう。撃破したときに次のボットを出します。

</Hint>

<Answer>

`BP_ShootingTestManager`でモードごとに終了条件を切り替えます。50体／100体排除では撃破数が指定数に達するまで続け、経過時間を記録して表示します。基本の30回モードも残します。

</Answer>

</Exercise>
